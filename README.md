## 📖 Sobre o projeto

O **GameZone** é um tema personalizado para WordPress, desenvolvido para criar um portal de notícias, análises e conteúdos sobre jogos eletrônicos.

O projeto utiliza um design gamer moderno, com cores escuras, detalhes em roxo, navegação intuitiva e layout responsivo.

### 🎯 Objetivos

- Desenvolver um tema WordPress próprio.
- Aplicar HTML5, CSS3, PHP e JavaScript.
- Organizar os arquivos seguindo as boas práticas do WordPress.
- Criar um portal dinâmico de notícias e reviews.
- Permitir a administração dos conteúdos pelo painel WordPress.

## 🖥️ Funcionalidades

- 📰 Notícias e lançamentos de games.
- ⭐ Reviews com notas de avaliação.
- 🎮 Publicações sobre jogos de PC e consoles.
- 🔎 Sistema de pesquisa.
- 📱 Layout responsivo.
- 🌙 Interface escura com detalhes neon.
- 💬 Comentários nas publicações.
- 🗂️ Categorias e arquivos de notícias.

## 🚀 Como instalar

### Método 1 — Instalação pelo painel WordPress

1. Baixe o arquivo `gamezone.zip`.
2. Acesse o painel administrativo do WordPress.
3. Entre em **Aparência → Temas → Adicionar novo**.
4. Clique em **Enviar tema**.
5. Selecione o arquivo ZIP.
6. Clique em **Instalar agora**.
7. Após a instalação, clique em **Ativar**.

### Método 2 — Instalação manual

Copie a pasta `gamezone` para:

```text
wp-content/themes/gamezone/
```

Depois, acesse **Aparência → Temas** e ative o GameZone.

## ⚙️ Configuração inicial

Após ativar o tema:

1. Acesse **Configurações → Geral** e configure o nome do site.
2. Entre em **Aparência → Personalizar**, quando disponível, para ajustar as opções do tema.
3. Crie as categorias Notícias, Reviews, Jogos e Guias.
4. Configure o menu principal.
5. Cadastre as primeiras publicações.
6. Adicione imagens destacadas aos artigos.

## 📰 Como publicar notícias

1. No painel WordPress, clique em **Posts → Adicionar novo**.
2. Digite o título da notícia.
3. Escreva o conteúdo.
4. Escolha a categoria.
5. Defina uma imagem destacada.
6. Clique em **Publicar**.

A publicação aparecerá automaticamente nas páginas correspondentes do portal.
